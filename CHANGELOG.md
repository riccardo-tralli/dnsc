## 0.1.0

- Initial version.
- Added DNS lookup commands for `A`, `AAAA`, `CNAME`, `MX`, `NS`, `PTR`, `SOA`, `SRV`, and `TXT` records.
- Added advanced email-related checks for `SPF`, `DKIM`, and `DMARC`.
- Added support for custom nameservers and configurable lookup timeouts.
- Added table and simple output modes, with optional record counting and full non-truncated output.
